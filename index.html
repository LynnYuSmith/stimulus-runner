How to use the Grating Stimulator

A browser grating presenter for a two-photon rig. Presentation runs entirely in the browser; a small local server (serve.py) only stores your saved protocols as files.

The two screens

  • Open stimulus window ↗ — a clean full-screen canvas; drag it to the mouse's monitor. No second monitor? Fullscreen here ⤢.
  • The operator screen is the cockpit — a live mirror of what the mouse sees is at the right.

Keyboard

  • Space — present the current grating; while a sequence runs it pauses (→ grey) / resumes (replays the interrupted grating).
  • G / Esc — grey · B — black · 1–8 — the eight quick orientations.

Setting a grating

  • Quick gratings present at a preset orientation but honour the moving / still toggle.
  • Custom grating: orientation, motion, waveform, spatial/temporal frequency, contrast, duration.
  • Click any number next to a slider to type an exact value.

Sequences

  • Build a list: + grating, + grey, + black, or a full 0–315° sweep. The header shows the block count and total length.
  • Drag a row by its ⠿ handle to reorder. Run queue plays them in order, each for its own duration.
  • Pause / resume a running sequence with Space or the ⏸ Pause button — pause drops to a grey screen, and resume replays the interrupted grating from the start (it is re-queued, not continued mid-drift). Both are written to the log.
  • Saved protocols live as files in the protocols/ folder — they travel with the folder to any computer.

Field zones (receptive-field mapping)

  • Divide the field into a grid (columns × rows, default 3 × 2) and pick a cell — the grating shows only there; the rest of the field stays grey.
  • The grating's spatial & temporal frequency are computed from the whole screen, so it is the same grating in every cell — only its location changes.
  • + zone sweep queues that grating in every cell in turn — a receptive-field map. ▣ Full field clears the selection.

Markers & export

  • A RED corner square pulses at each onset, pulse-count coded: grey = 1, static = 2, moving = 3 (a photodiode reads it).
  • Export protocol writes the played sequence (JSON) to overlay onto the recording; the trial log exports as CSV / JSON.
